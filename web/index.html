Cómo instalar

  1. Conecta la placa al ordenador con un cable USB-C de datos (algunos cables solo cargan).
  2. Pulsa Conectar e instalar y elige el puerto de la placa (suele llamarse USB JTAG/serial debug unit o ttyACM0).
  3. Elige Instalar. Puedes marcar borrar el dispositivo si quieres empezar de cero.
  4. Espera alrededor de un minuto. Al terminar, la placa se reinicia con el nuevo firmware.

Después de instalarlo, el mismo botón te deja abrir los registros (monitor serie) para ver los mensajes ESP_LOGI que escribe el programa.

Si no conecta

  • Modo descarga: desconecta el USB, mantén pulsado BOOT, conecta el USB y suelta BOOT. Vuelve a intentarlo. Al terminar, desconecta y conecta el USB para arrancar.
  • Linux: tu usuario debe tener permiso sobre el puerto: sudo usermod -aG dialout $USER y vuelve a iniciar sesión.
  • Cierra cualquier otro programa que esté usando el puerto (monitor serie, Arduino IDE, VS Code…).

Qué incluye

Menú con los 3 botones, enlaces de ayuda en QR y pruebas de pantalla, botones, batería, acelerómetro/giroscopio, altavoz, microSD y bus I2C, además de una app plantilla para empezar a programar.
