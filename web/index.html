ESP32-S3-LCD-1.54 Starter

Install firmware on the Waveshare ESP32-S3-LCD-1.54.

Open this page in desktop Chrome or Edge. Open the HTTPS installer directly to allow serial access.
  1. Plug the board into your computer with a USB-C data cable.
  2. Choose Connect and select the board's serial port.
  3. Choose Install and wait for it to finish.

Erasing the device is optional and deletes data saved in flash.

Board won't connect?
  • Close any serial monitor or other app using the port.
  • On Linux, check that your user has permission to open the serial port.
  • Unplug USB, hold BOOT, plug USB back in, then release BOOT and try again. After installing, reconnect USB without holding BOOT.
